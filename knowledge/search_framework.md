# Search Framework

## Purpose
- Define the minimum search behavior for V1 project discovery.

## Search Goal Categories
- user-requested market scan
- user-requested project scan
- user-requested opportunity scan

## Keyword Breakdown Method
- Start from the user's search instruction or market range.
- Extract only core terms needed to find candidate projects.
- Do not expand into unrelated industries or speculative branches.

## Search Steps
- Read the provided search scope.
- Identify candidate projects or opportunities.
- Filter out obviously low-value or off-scope items.
- Hand the short list to the proposal stage.

## Scope Boundaries
- Do not search unless the user provides a search trigger.
- Do not turn one search request into a broad autonomous research program.
- Do not proceed into deep due diligence in V1.

## Information Organization Format
- Keep candidate findings short and proposal-ready.
- Organize results as project candidates, not long-form reports.
